# CONTATTI / PRENOTAZIONE — Reference Card

## Status
ACTIVE — Page 06

## Primary real-world reference
George Northwood — Find Us / Wells St.
https://www.georgenorthwood.com/pages/find-us-wells-st

The live page was inspected directly before implementation.

## Observed design / conversion logic
- minimal contact page rather than a form-heavy funnel;
- clear top-level booking access;
- strong location identity;
- contact details grouped separately from booking actions;
- two-column information hierarchy on desktop;
- generous whitespace and neutral palette;
- address / hours / map are treated as factual utility content;
- booking CTA is prominent and distinct from informational contact details.

## What SEZIONE adapts
- clear booking hierarchy;
- grouped contact / location information;
- neutral editorial styling;
- simple rectangular action treatment;
- factual information separated from conversion actions;
- no unnecessary lead-capture form.

## What SEZIONE does not copy
- George Northwood address, phone, email or hours;
- cancellation policy;
- booking provider;
- map coordinates;
- copy;
- exact layout measurements;
- textured background assets.

## Demo integrity rule
SEZIONE is a concept demo and currently has no verified:
- address;
- opening hours;
- phone number;
- WhatsApp number;
- email;
- booking provider;
- live appointment availability.

Therefore Page 06 uses clearly labeled production integration slots instead of fabricated contact data.

## Page architecture
1. Booking / contact statement
2. Two routes: “I know what I want” vs “first visit”
3. Verified-data integration slots
4. Three useful pre-booking routes
5. Final integration-ready statement

## Image plan
No imagery is used on Page 06.

Reason:
- the primary reference is primarily utility/contact driven;
- there is no verified physical SEZIONE location to illustrate;
- adding generic imagery would weaken the factual nature of the page.

## Personal-data rule
No form is implemented.
No personal data is collected.
No fake email, phone number or address is included.
