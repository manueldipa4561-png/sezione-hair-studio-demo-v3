# HOME — Reference Card

## Status
ACTIVE — Page 01

## Primary visual reference
George Northwood
https://www.georgenorthwood.com/

### Visual logic adapted
- high-contrast black / white salon identity;
- sparse navigation;
- image-first editorial hero;
- oversized typography;
- restrained interface;
- salon/interior imagery treated like editorial photography rather than generic stock.

## Secondary reference — salon-space composition
Hershesons / Stores
https://www.hershesons.com/pages/stores

Used only for:
- large interior image paired with compact copy;
- strong image/text proportion;
- simple black/white service hierarchy.

## Secondary reference — service clarity
Josh Wood Colour Atelier
https://joshwoodcolour.com/pages/josh-wood-colour-hair-salon-london

Used only for:
- clear grouping of services;
- consultation-led language;
- reducing uncertainty before booking.

## SEZIONE palette
- Paper: #F5F3EE
- White: #FFFFFF
- Ink: #0B0B0A
- Stone: #CFC9BE
- Mist: #D9DAD5

The palette follows the restrained monochrome / natural-material logic of high-end salon references without copying a specific brand system.
