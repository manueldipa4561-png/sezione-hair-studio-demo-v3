## Primary real-world reference
Hershesons — Stores / Fitzrovia
https://www.hershesons.com/pages/stores

The live page was inspected directly before implementation.

## Observed design logic
- full-width salon-interior imagery establishes context immediately;
- white background and restrained black typography let the space carry the identity;
- large uppercase spatial statements;
- generous vertical padding;
- two-column interior/text blocks;
- warm, slightly desaturated real interior photography;
- salon interiors function as the primary storytelling device;
- location blocks use simple hierarchy rather than decorative UI;
- alternating image/text rhythm distinguishes areas without changing the core visual language.

## What SEZIONE adapts
- real-space storytelling instead of abstract brand graphics;
- full-width interior-led opening;
- white / paper / stone palette;
- large editorial spatial typography;
- generous whitespace;
- interior image paired with compact explanatory copy;
- material / light / spacing language rather than decorative feature lists.

## What SEZIONE does not copy
- Hershesons name, logo or wording;
- exact salon descriptions;
- addresses or telephone numbers;
- exact layout measurements;
- exact button treatment;
- Hershesons interior photography;
- claims about an actual SEZIONE physical location.

## SEZIONE Studio concept
The page communicates four spatial principles:
1. Light
2. Material
3. Distance
4. Time

These are **concept design principles**, not verified claims about an operating SEZIONE location.

## Implementation imagery
